## 🚀 Quick Setup & Installation

### 1. Clone the Repository
```bash
git clone https://github.com/Faizan1998Sayyed/OIBSIP.git
cd OIBSIP
```

### 2. Set Up a Virtual Environment (Recommended)
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate
```

### 3. Install Dependencies
```bash
# Task 2 (BMI Calculator):
pip install -r Python-Task2-BMICalculator/requirements.txt

# Task 3 (Password Generator):
pip install -r Python-Task3-PasswordGenerator/requirements.txt

# Task 4 (Weather App):
pip install -r Python-Task4-WeatherApp/requirements.txt
```
